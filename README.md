# 🎯 우리 반 목표 게이지

반 전체가 함께 점수를 모아 게이지를 채우면 보상을 받는 학급 운영 도구예요. 전자칠판이나 선생님 컴퓨터에 띄워 두고 써요.

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 첫 화면 |
| `style.css` | 디자인 |
| `app.js` | 동작 |
| `data.js` | 처음 점수 버튼, 기본 목표, 응원 메시지 (화면의 ⚙️ 설정에서도 바꿀 수 있어요) |

## 깃허브 페이지로 배포하기

1. github.com → **+** → **New repository** → 이름(예: `class-goal`), **Public** → **Create repository**
2. **uploading an existing file** → 파일 5개 끌어다 놓기 → **Commit changes**
3. **Settings → Pages** → Branch `main` / `/(root)` → **Save**
4. 1~2분 뒤 주소: `https://내아이디.github.io/class-goal/`

## 쓰는 방법

1. **⚙️ 설정**에서 목표 이름, 보상, 목표 점수, 게이지 모양을 정해요.
   - 🫙 **구슬 병 채우기**: 점수만큼 구슬이 떨어져 병이 채워져요
   - 🌳 **나무 키우기**: 씨앗 → 새싹 → 나무 → 꽃 → 열매
   - 🚀 **달까지 로켓**: 지구에서 달까지 로켓이 올라가요
2. 좋은 일이 있을 때 오른쪽 **점수 버튼**을 눌러요. 키보드 숫자 **1~9**로도 줄 수 있어요.
   - 목록에 없는 이유는 아래 칸에 적고 점수를 넣어 **+ 주기**
   - 잘못 눌렀으면 **↩️ 방금 것 취소**
3. 25%, 50%, 75%, 90%가 되면 응원 메시지가 떠요.
4. 목표 점수를 채우면 🎉 축하 화면이 나와요. **명예의 전당에 올리고 새 목표 정하기**를 누르면 다음 목표로 넘어가요.
5. **📺 발표 모드**를 누르면 버튼이 사라지고 게이지만 크게 보여요. 학생들이 버튼을 누를 걱정이 없어요.

## 알아 두세요

- 점수는 **이 컴퓨터 브라우저에만** 저장돼요. 브라우저 기록을 지우면 사라질 수 있어요.
- 가끔 **⚙️ 설정 → 📥 백업 파일 받기**로 받아 두세요. 컴퓨터를 바꾸면 **📤 백업 불러오기**로 그대로 옮길 수 있어요.
- 점수 버튼(이유, 그림, 점수)은 ⚙️ 설정에서 더하고, 고치고, 지울 수 있어요.

## 운영 팁

- 목표와 보상은 **학급 회의에서 학생들과 함께** 정하면 더 열심히 해요.
- 처음에는 목표를 작게(20~30점) 잡아 빨리 성공하는 경험을 주세요. 그다음부터 조금씩 늘려요.
- 점수는 "반 전체"의 것이에요. 개인에게 벌점 대신 반 전체에 칭찬을 더해 주는 방식으로 쓰면 좋아요.
